# SHOSO Books 📚

קורא ספרים שולחני **ל-Windows בלבד** – חלופה מלאה ל-Readera לאנדרואיד,
עם ממשק עברי מימין־לשמאל, ספרייה מקומית מהירה, קורא EPUB/PDF מתקדם,
סימניות, חיפוש בתוך הספר והקראת טקסט (TTS).

> Built with **Electron + React + Vite**. כל הספרים נשארים על המחשב – אין שרת, אין חשבון, אין אינטרנט.

---

## התקנה והרצה ב-Windows

### אפשרות 1 – הרצה מהירה (מומלץ לפיתוח)

1. התקן [Node.js LTS](https://nodejs.org) (גרסה 18 ומעלה).
2. הורד/שבט את הפרויקט.
3. לחץ פעמיים על **`run-windows.bat`**.
   הסקריפט מתקין תלויות בפעם הראשונה, בונה את הממשק ומפעיל את האפליקציה.

או ידנית ב-PowerShell / CMD:

```powershell
npm install
npm run start:app
```

### אפשרות 2 – הורדת `.exe` מוכן (בלי לבנות לבד)

📄 מדריך מלא: **[BUILD-EXE.md](BUILD-EXE.md)**

הפרויקט כולל workflow של GitHub Actions שבונה מתקין אמיתי ל-Windows:

1. היכנס ל-**Actions → Build Windows app → Run workflow**.
2. בסיום, הורד את הארטיפקט **`SHOSO-Books-Windows`** (מכיל מתקין + Portable).
3. או דחוף תג (`git tag v1.0.0 && git push --tags`) – הקבצים יצורפו אוטומטית ל-Release.

### אפשרות 3 – בניית `.exe` מקומית (פשוט מאוד)

לחץ פעמיים על **`build-exe.bat`** – הסקריפט מתקין, בונה, ופותח את תיקיית `release\` עם הקבצים.

או ידנית:

```powershell
npm install
npm run dist          # מייצר גם מתקין NSIS וגם Portable
```

הקבצים יופיעו בתיקייה `release\`:

| קובץ | תיאור |
| --- | --- |
| `SHOSO-Books-1.0.0-x64.exe` | מתקין עם קיצור דרך בשולחן העבודה |
| `SHOSO-Books-1.0.0-portable.exe` | גרסה ניידת – להריץ מכונן USB בלי התקנה |

> בנייה לקבצי `.exe` דורשת Windows (או Wine/Linux עם `electron-builder --win`).
> סמל האפליקציה נמצא ב־`build/icon.ico`.

## מה יש בפנים

### מהמדף אל הספר (כמו ReadEra)
- **נגיעה בספר פותחת את מסך התיאור** – שלב הביניים של ReadEra: כריכה, כותרת, מחבר,
  אחוז הקריאה, פעולות עם תוויות (מועדפים / לקריאה / נקרא / הוסף למדף / אשפה) ולמטה
  **התיאור עצמו**, שנקרא מתוך הקובץ: `dc:description` ב-EPUB, `<annotation>` ב-FB2,
  מטא-דאטה ועמוד ראשון ב-PDF, והפסקה הפותחת ב-TXT/MD/HTML. רק "קרא את הספר" פותח את הקורא.
- **בחירה מרובה** – סמן ✓ שמופיע על הכריכה, לחיצה ארוכה, לחיצה ימנית או ⌘/Ctrl-לחיצה;
  פס הפעולות מציג פתח לקריאה · הוסף למדף · העבר לאשפה · בחר הכול. הספרים שנבחרו
  מסומנים בטורקיז, ולחיצה נוספת על ספר מבטלת את הבחירה שלו.

### מי אחראית על הסריקה
התהליך הראשי (Electron) הוא הבעלים היחיד של הספרייה — כל סריקה עוברת דרכו:
- **בכל הפעלה** הספרייה מותאמת למה שיש על הדיסק: קבצים חדשים נכנסים, קבצים שהשתנו
  נקראים מחדש, וספרים שהקובץ שלהם נעלם יורדים מהרשימה (רק עבור תיקיות שהשיבו —
  כונן מנותק לא מרוקן את הספרייה). גם "סרוק עכשיו" ידני קיים בתיקיות ובהגדרות.
- **מעקב אחרי תיקיות**: שינוי בקובץ/תיקייה נסרק מחדש אוטומטית תוך שנייה וחצי.
- **כריכות**: זיהוי הכריכה של EPUB לפי הסדר שהתקן מגדיר (`properties="cover-image"`,
  `<meta name="cover">`, `<guide type="cover">`, ואז שם קובץ עם "cover"), ‏FB2 לפי
  ה-`content-type` של ה-`<binary>`, ‏PDF מעמוד 1, ותמונת `cover.jpg` מתיקיית הספר.
  כריכה שחולצה נשמרת בתיקיית הנתונים ובספרייה עצמה, כך שהיא מופיעה מיד בהפעלה הבאה
  ואין צורך לפענח את הקובץ שוב; ספר שאין בו אמנות מקבל כריכה מודפסת ולא מלבן ריק.

### ז׳אנרים וסגנונות
- **מדף לכל ז׳אנר** – הז׳אנר נקרא מהקובץ עצמו: `dc:subject` ב-EPUB, `<genre>` ב-FB2
  (כולל קודים כמו `sf_history` שמתורגמים לעברית) ו-`Keywords` ב-PDF.
- **הוספה ידנית** – במסך הפרטים של הספר אפשר להוסיף ז׳אנר בעצמך; הוא נשמר בספרייה
  ונשאר גם כשהסריקה כותבת מחדש את רשומת הספר.
- **מדפים לפי ז׳אנר** – כפתור במסך "מדפים" יוצר מדף אחד לכל ז׳אנר (ולא כופה כפילות
  כשמריצים אותו שוב).

### ספרייה וניהול
- **ספרייה גדולה** – הרשימה מציגה את כל הספרים בבת אחת: פס הגלילה מייצג את הספרייה
  כולה, בלי כפתור "טען עוד" ובלי מונה. בפועל נבנה רק החלון הנראה לעין (בדיקת CI:
  10,000 ספרים ⇒ פחות מ-60 שורות ב-DOM), ולכן הגלילה נשארת חלקה כמו באפליקציית תמונות.
- **סריקת תיקיות רקורסיבית** – EPUB, PDF, TXT, FB2, HTML/HTM, MD (זיהוי MOBI/DJVU).
- קריאת **מטא-דאטה מ-EPUB (OPF)** – כותרת, מחבר, שפה, עטיפה, מספר פרקים; **FB2** – כותרת, מחבר, עטיפה; **PDF** – כותרת, מחבר, מספר עמודים; **TXT** – כותרת וספירת מילים.
- **עטיפות ספרים** מ-EPUB/FB2 או תמונת `cover.jpg` מהתיקייה (עם מטמון ב־`%APPDATA%\SHOSO Books\covers`).
- **גרירה ושחרור** של תיקיות וקבצים מהחלון של Windows ישירות לאפליקציה.
- **פתיחה מ-Windows** – קובץ שנפתח דרך האפליקציה (לחיצה כפולה / „פתח עם“) נכנס לספרייה
  ונפתח לקריאה. בהתקנה נרשמים epub · fb2 · mobi · azw3 · pdf; Windows 10/11 מחייב את
  המשתמש לבחור את ברירת המחדל פעם אחת, ולכן יש בהגדרות כפתור שמפתח את המסך הזה.
- **שליטה בסריקה ובהסרה** (הגדרות): סריקה אוטומטית בהפעלה, מעקב תיקיות, הסרת ספרים
  שנעלמו, והאם הסרת תיקייה מעבירה את ספריה לאשפה או משאירה אותם בספרייה.
- תצוגות: בית (המשך קריאה + סטטיסטיקות), ספרייה, מחברים, פורמטים, תיקיות, מועדפים, היסטוריה, מדפים (אוספים אישיים).
- **חיפוש חכם בעברית** – מתעלם מניקוד, תומך בכמה מילים ובאנגלית, ומסנן בזמן אמת.
- מיון לפי שם / מחבר / פורמט / גודל / תאריך הוספה / התקדמות; תצוגת רשת או רשימה.
- שמירה אוטומטית של הספרייה (`library.json`) וההגדרות (`state.json`) – בין הפעלות.

### קריאה (כמו Readera)
- **EPUB מלא** – פענוח OPF/NCX/Nav, תוכן עניינים, פרקים, תמונות, RTL/LTR אוטומטי.
- **PDF מלא** – רינדור עמודים עם pdf.js, זום, דפדוף, מחוון עמודים, שמירת עמוד אחרון.
- **TXT / FB2 / HTML / Markdown** – פיצול לפרקים, פסקאות, כותרות.
- **שמירת התקדמות אוטומטית** לכל ספר (פרק + גלילה / עמוד + אחוז), "המשך קריאה" בבית, סימון ספרים שהסתיימו.
- **סימניות** – הוספה בלחיצה אחת (B), רשימה וקפיצה לסימנייה.
- **חיפוש בתוך הספר** – תוצאות עם תקציר וקפיצה לפרק.
- **הקראת טקסט (TTS)** – הקראת הפרק הנוכחי בעברית/אנגלית עם מהירות 0.75x–2x.
- **הדגשות** – סימון קטע בטקסט פותח סרגל צף עם 4 צבעים (צהוב/ירוק/תכלת/ורוד) והעתקה;
  ההדגשות נשמרות לפי הספר, מופיעות ברשימה עם קפיצה לפרק, ולחיצה על הדגשה מסירה אותה.
  החיפוש אחרי הקטע מתעלם מניקוד ומרווחים, כך שההדגשה שורדת שינוי גופן או כיבוי ניקוד.
- **ניקוד** – switch בהגדרות הקריאה שמציג או מסתיר הניקוד בטקסט (המלאי נשמר בקובץ).
- **קריאה אוטומטית** – גלילה אוטומטית בקצב שנבחר (P), עם עצירה בגלגלת העכבר ובסוף הספר;
  הסרגלים מתעמעמים בזמן הקריאה.
- **תמונות בתוך הספר** – גם עמוד הכריכה מסוג `<svg><image xlink:href>` וגם תמונות FB2
  מה-`<binary>` מוצגות (עד היום הן לא נטענו).
- **הגדרות טיפוגרפיה** – 4 ערכות נושא (בהיר/כהה/ספיה/לילה), גופן, גודל, ריווח שורות, שוליים, רוחב עמוד, יישור דו-צדדי, מקפים.
- **ממשק מתחבא** – סרגלי הקורא מתחבאים אוטומטית, קיצורי מקלדת מלאים (F1).

### אופליין
- **האפליקציה עובדת לגמרי אופליין ואין בה שום בקשת רשת** – הספרים, הספרייה, העטיפות,
  ההתקדמות, ההדגשות וההגדרות נשמרים על המחשב. אין חשבון, אין ענן, אין בדיקת עדכונים
  ואין טלמטריה.
- **עדכון ידני** – מורידים את קובץ ההתקנה החדש ומריצים אותו: הוא מחליף את הגרסה
  הקיימת באותה תיקייה (`%LOCALAPPDATA%\Programs\SHOSO Books`), לא נוצרת התקנה כפולה,
  והספרייה ב-`%APPDATA%\SHOSO Books` נשמרת כמו שהיא.
- **גרסה ניידת** – פשוט מחליפים את קובץ ה-`.exe`; הנתונים יושבים לידו בתיקייה
  `SHOSO Books Data`.

### עיצוב
- ממשק **עברי RTL** מלא, כהה ובהיר, 5 צבעי מבטא.
- אנימציות עדינות, גריד ספרים עם עטיפות והתקדמות.

## מבנה הפרויקט

```
electron/
  main.cjs        תהליך ראשי: חלון, סריקת ספרייה, פרוטוקול מדיה תומך Range, שמירת JSON
  preload.cjs     גשר מאובטח (contextBridge) בין ה-UI ל-Windows API
src/
  lib/
    store.js      סטור מרכזי (observer), ספרייה, התקדמות, סימניות, מדפים, שמירה
    parsers.js    פענוח EPUB / PDF / FB2 / TXT / HTML / MD + חיפוש בספר
    platform.js   הפשטה: Electron מול דפדפן (מצב דמו)
    format.js     עזרי תצוגה, ניקוד עברי, מיון, זיהוי כיוון
    demo.js       יצירת ספרי דמו (EPUB/TXT/FB2 אמיתיים) בתוך הדפדפן
    description.js  חילוץ התיאור (annotation) מתוך EPUB/FB2/PDF/TXT
  components/     Reader, Sidebar, TopBar, BookCard, Cover…
  views/          Home, Library, Authors, Formats, Collections, Settings…
tests/            בדיקות Vitest + Testing Library
build/            אייקונים ל-Windows
```

## הרצת מצב דמו בדפדפן

`npm run dev` ואז בהגדרות „טען ספרי דמו” – האפליקציה מייצרת שלושה ספרים אמיתיים
(EPUB בעברית שנבנה עם JSZip, TXT באנגלית, FB2 בעברית) כדי לבחון את כל הממשק בלי קבצים.

## הערות

- פורמטים MOBI ו-DJVU מזוהים בספרייה אך אינם ניתנים לקריאה בגרסה זו (דורשים מנוע ייעודי) – האפליקציה תציג הודעה ברורה ותציע המרה ל-EPUB/PDF.
- כל הנתונים מקומיים: `%APPDATA%\SHOSO Books\`.
