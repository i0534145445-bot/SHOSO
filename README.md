# SHOSO Music 🎧

נגן מוזיקה שולחני **ל-Windows בלבד** – חלופה מלאה לנגני המובייל (בסגנון Musicolet / Musicat),
עם ממשק עברי מימין־לשמאל, ספרייה מקומית מהירה, מילות שיר מסונכרנות, אקולייזר ופלייליסטים.

> Built with **Electron + React + Vite**. כל המוזיקה נשארת על המחשב – אין שרת, אין חשבון, אין אינטרנט.

---

## התקנה והרצה ב-Windows

### אפשרות 1 – הרצה מהירה (מומלץ לפיתוח)

1. התקן [Node.js LTS](https://nodejs.org) (גרסה 18 ומעלה).
2. הורד/שבט את הפרויקט.
3. לחץ פעמיים על **`run-windows.bat`**.
   הסקריפט מתקין תלויות בפעם הראשונה, בונה את הממשק ומפעיל את האפליקציה.

או ידנית ב-PowerShell / CMD:

```powershell
npm install
npm run start:app
```

### אפשרות 2 – הורדת `.exe` מוכן (בלי לבנות לבד)

הפרויקט כולל workflow של GitHub Actions שבונה מתקין אמיתי ל-Windows:

1. היכנס ל-**Actions → Build Windows app → Run workflow**.
2. בסיום, הורד את הארטיפקט **`SHOSO-Music-Windows`** (מכיל מתקין + Portable).
3. או דחוף תג (`git tag v1.0.0 && git push --tags`) – הקבצים יצורפו אוטומטית ל-Release.

### אפשרות 3 – בניית `.exe` מקומית

```powershell
npm install
npm run dist          # מייצר גם מתקין NSIS וגם Portable
```

הקבצים יופיעו בתיקייה `release\`:

| קובץ | תיאור |
| --- | --- |
| `SHOSO-Music-1.0.0-x64.exe` | מתקין עם קיצור דרך בשולחן העבודה |
| `SHOSO-Music-1.0.0-portable.exe` | גרסה ניידת – להריץ מכונן USB בלי התקנה |

> בנייה לקבצי `.exe` דורשת Windows (או Wine/Linux עם `electron-builder --win`).
> סמל האפליקציה נמצא ב־`build/icon.ico`.

## מה יש בפנים

### ספרייה וניהול
- **סריקת תיקיות רקורסיבית** – MP3, FLAC, M4A/AAC, WAV, OGG/Opus, WMA, AIFF, WV.
- קריאת **תגי ID3 / Vorbis / MP4** דרך `music-metadata`: שם, אמן, אלבום, שנה, ז׳אנר, מספר רצועה, בייטרט, סמפל-רייט.
- **עטיפות אלבום** מוטמעות (עם שמירה למטמון ב־`%APPDATA%\SHOSO Music\covers`) או `cover.jpg`/`folder.png` מהתיקייה.
- **גרירה ושחרור** של תיקיות וקבצים מהחלון של Windows ישירות לאפליקציה.
- תצוגות: בית, שירים, אלבומים, אמנים, ז׳אנרים, תיקיות, מועדפים, היסטוריה, תור נגינה, פלייליסטים.
- **חיפוש חכם בעברית** – מתעלם מניקוד, תומך בכמה מילים ובאנגלית, ומסנן בזמן אמת.
- מיון לפי שיר / אלבום / אמן / משך / שנה / תאריך הוספה.
- שמירה אוטומטית של הספרייה (`library.json`) וההגדרות (`state.json`) – בין הפעלות.

### נגינה
- נגן עם **Seek מדויק**, חיווי זמן, שליטה בעוצמה, השתקה.
- **אקראי**, **חזרה על הכל / על שיר**, תור נגינה חכם עם "נגן בהמשך" ו"הוסף לתור".
- **מהירות נגינה 0.5x–2x** עם שמירה על גובה הצליל (מעולה ללימוד שפות / תרגול).
- **חזרה A‑B** – סימון קטע לחזרה אינסופית (תרגול סולו / לימוד שפה) + **טיימר שינה** (15–90 דקות).
- **אקולייזר 10 ערוצים** (31Hz–16kHz) + Pre‑amp + 9 פריסטים (בס, ווקאל, רוק, פופ, ג׳אז, קלאסי, אלקטרוני, ועוד) דרך Web Audio API.
- **ויזואליזר ספקטרום** חי על עטיפת השיר.
- **מילות שיר**: קובץ `.lrc` סמוך לשיר (או תג מילים ב-ID3) – מסונכרן בזמן אמת, לחיצה על שורה מדלגת לזמן שלה.
- קיצורי מקלדת מלאים (רשימה בקובץ – F1).

### עיצוב
- ממשק **עברי RTL** מלא, כהה ובהיר, 5 צבעי מבטא.
- אנימציות עדינות, גריד אלבומים עם כפתור נגינה מהיר.

## מבנה הפרויקט

```
electron/
  main.cjs        תהליך ראשי: חלון, סריקת ספרייה, פרוטוקול מדיה תומך Range, שמירת JSON
  preload.cjs     גשר מאובטח (contextBridge) בין ה-UI ל-Windows API
src/
  lib/
    store.js      סטור מרכזי (observer), ספרייה, תור, פלייליסטים, שמירה
    audio.js      מנוע נגינה + גרף Web Audio (EQ, Pre-amp, Analyser)
    platform.js   הפשטה: Electron מול דפדפן (מצב דמו)
    lrc.js        פענוח LRC וסנכרון שורות
    format.js     עזרי תצוגה, ניקוד עברי, מיון
    demo.js       יצירת שירי דמו (WAV) בתוך הדפדפן
  components/     PlayerBar, Sidebar, TrackList, Equalizer, LyricsPanel…
  views/          Home, Songs, Albums, Artists, Playlists, Settings…
tests/            בדיקות Vitest + Testing Library
build/            אייקונים ל-Windows
```

## בדיקות

```powershell
npm test
```

19 בדיקות אוטומטיות (Vitest + Testing Library) מכסות: פענוח LRC וסנכרון, חיפוש עברי עם ניקוד,
מיון וקיבוץ אלבומים/אמנים/ז׳אנרים, ניווט בכל המסכים, נגינה ותור, פלייליסטים (הוספה/הסרה/סדר),
אקולייזר ופריסטים, חזרה A‑B, טיימר שינה, ויצירת ספריית הדמו.

## הרצת מצב דמו בדפדפן

`npm run dev` ואז „נסה עם מוזיקת דמו” – האפליקציה מייצרת שישה קטעים אינסטרומנטליים,
עם עטיפות ומילים מסונכרנות, כדי לבחון את כל הממשק בלי קבצי מוזיקה.

## הערות

- ווידאו/קול: קבצי `.wma` ו-`.wv` יוצגו בספרייה אך נגינתם תלויה בתמיכת מפענחי המדיה של Windows.
- כל הנתונים מקומיים: `%APPDATA%\SHOSO Music\`.
