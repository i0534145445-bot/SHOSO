# SHOSO מיוזיק — נגן מוזיקה מקומי לווינדוס

נגן מוזיקה לשולחן העבודה של Windows, בסגנון **Musicolet**: מנגן קבצים מקומיים בלבד,
ללא רשת, ללא פרסומות, ללא מעקב. כל הממשק בעברית ובפריסה מימין לשמאל (RTL).

| | |
|---|---|
| **גרסה** | 1.0.0 |
| **פלטפורמה** | Windows 10 / 11 — x64 (וגם 7/8/8.1 אחרי עדכון UCRT ‏KB2999226) |
| **קבצים מוכנים** | `dist/SHOSO-Setup.exe` (מתקין) · `dist/SHOSO-Music.exe` (נייד) |
| **שפה** | עברית (RTL), כולל ערכת נושא כהה/בהירה |
| **תלות** | אפס — קובץ EXE יחיד סטטי, בלי התקנת ספריות |

---

## התקנה

### אפשרות 1 — קובץ התקנה (מומלץ)
1. הורידו/העתיקו את `dist/SHOSO-Setup.exe`.
2. הפעילו בלחיצה כפולה. **אין צורך בהרשאות מנהל** — ההתקנה היא per-user.
3. לחצו **התקנה**.

המתקין מבצע:
* מעתיק את הנגן ל‑`%LOCALAPPDATA%\Programs\SHOSO\SHOSO-Music.exe`
* יוצר קיצור דרך בתפריט ההתחלה (ובשולחן העבודה — לפי הבחירה)
* רושם את SHOSO כנגן מוצע לסיומות: `mp3, flac, wav, m4a, m4b, aac, ogg, oga, opus, wma`
* רושם ערך הסרה ב"הוספה/הסרה של תוכניות" (Uninstall)

**הסרה:** הגדרות → אפליקציות → SHOSO Music → הסרה, או הפעלת
`%LOCALAPPDATA%\Programs\SHOSO\Uninstall.exe` (אפשר גם `SHOSO-Setup.exe /uninstall`).
קובצי המוזיקה והספרייה לא נמחקים; נתוני התוכנית נשארים ב‑`%APPDATA%\SHOSO`.

### אפשרות 2 — הפעלה ניידת (Portable)
פשוט הפעילו את `dist/SHOSO-Music.exe` מכל תיקייה (דיסק-און-קי כולל). אין התקנה כלל.

## שימוש ראשון

1. פתחו את התוכנית. אם הספרייה ריקה יופיע המסך "הספרייה ריקה".
2. לחצו על **+** בסרגל העליון (או תפריט ← **הוספת תיקייה לספרייה...**) ובחרו את תיקיית המוזיקה.
3. הסריקה רצה ברקע; השירים מופיעים ברשימה תוך כדי סריקה.
4. לחיצה כפולה על שיר מתחילה נגינה. גרירת קבצים/תיקיות אל החלון מוסיפה אותם לתור.

## מה יש בתוכנה

**ממשק בסגנון Musicolet**
* שורת תור נפתחת למעלה ("3. תור ג'") עם ניקוי תור, ושורת פעולה עם מונה המיקום בתור
* רשימות דו־ ושלוש־שורתיות עם תמונת עטיפה ריבועה וידית אחיזה, והשיר הנוכחי ממוסגר בירוק
* שורת חיפוש מעל סרגל הניווט התחתון: תורים, שירים, תיקיות, אלבומים, אמנים, פלייליסטים, "מנגן כעת" ותפריט — הפריט הפעיל מסומן בקו ירוק
* מסך "מנגן כעת" מלא: עטיפה גדולה, שם/אמן/אלבום, שורת פעולות (לב, מאפיינים, הוספה לפלייליסט, שינה, חזרה, ערבוב), פס התקדמות ובקרי נגינה
* ערכת נושא כהה (ברירת מחדל) או בהירה, שתיהן עם ההדגשה הירוקה של Musicolet

**ספרייה ותצוגות**
* 6 תצוגות: שירים · אלבומים · אמנים · תיקיות · פלייליסטים · התור (קיצורים: `Ctrl+1`…`Ctrl+6`)
* קריאת תגיות: ID3v1, ID3v2.2/2.3/2.4 (כולל UTF‑16), Vorbis Comments ב‑FLAC, ו‑MP4/M4A (`©nam`, `©ART`…)
* חישוב משך מדויק מ‑Xing/VBRI, מ‑FLAC STREAMINFO, או הערכה מ‑bitrate
* חיפוש חי (מקבל עברית ואנגלית, לא רגיש לרישיות) — `Ctrl+F`
* מיון לפי שם/אמן/אלבום/אורך; ניקוד לפי שדות
* עטיפות אלבום: APIC מוטמע, `cover.jpg` בתיקייה, עם מטמון LRU וריסוס ב‑GDI+

**נגינה**
* מנוע MCI של Windows (דרך `mciqtz`/DirectShow) — mp3, wav, wma, m4a ועוד לפי המפענחים המותקנים
* 10 תורי נגינה נפרדים ("תור 1"…"תור 10") — כל תור שומר מיקום, מצב והיסטוריה
* ערבוב (shuffle) וחזרה (off / שיר אחד / כל התור), עם שמירת מצב בין הפעלות
* פס התקדמות עם גרירה, בקרת עוצמה, מיקום/אורך בזמן אמת
* מקשי מדיה של המקלדת + `WM_APPCOMMAND` (נגינה/השהיה, הבא, הקודם, עצירה)
* חיפוש מהיר ברשימה על ידי הקלדת אותיות

**פלייליסטים ומועדפים**
* פלייליסטים ללא הגבלה, יצירה/שינוי שם/מחיקה
* פלייליסט "מועדפים" מובנה + כפתור לב ❤
* הוספת שירים/אלבומים/אמנים/תיקיות שלמות לתור או לפלייליסט

**נוחות**
* טיימר שינה: 15/30/45/60/90 דקות או "בסוף השיר הנוכחי"
* מזעור למגש המערכת (Tray) עם תפריט נגינה והצגת השיר הנוכחי ב־tooltip
* מופע יחיד (single instance): הפעלה שנייה מעבירה קבצים לחלון הפתוח
* ערכת נושא כהה (ברירת מחדל) או בהירה, מותאמת DPI (Per‑Monitor V2)
* דוח אבחון (`תפריט ← יצירת דוח אבחון`) ולוג ב‑`%APPDATA%\SHOSO\log.txt`
* שמירה אוטומטית של הספרייה, התורים וההגדרות; זיהוי קבצים שנמחקו בסריקה מחדש

**מה אין בגרסה 1.0** — אקולייזר (מנוע MCI של Windows לא חושף עיבוד אות), כתובת/סינכרון מילים,
והמרת פורמטים. ראו "תוכניות להמשך" למטה.

## בנייה מקוד המקור

הפרויקט נבנה ב‑C++17 ללא תלויות צד שלישי. שכבת הליבה (`src/core`) טהורה ונבדקת
על Linux; שכבת Windows (`src/win`) היא UI + נגינה בלבד.

```bash
./build.sh --tests     # הרצת 218 בדיקות יחידה של הליבה + בניית שני קבצי ה‑EXE
./build.sh             # בנייה בלבד
```

הבנייה משתמשת ב‑**Zig** ככלי cross‑compile (יעד `x86_64-windows-gnu`, קישור סטטי).
אם `zig` לא נמצא ב‑PATH, הסקריפט מחפש `tools/zig/zig`:

```bash
bash tools/get_zig.sh          # מוריד את zig דרך pip לתוך tools/zig (מחוץ ל‑git)
```

**מבנה:**

```
src/core/   str, tags, library, queue, store  — לוגיקה נקייה, UTF‑8, נבדקת
src/win/    main, ui_main, ui_actions, ui_lists, ui_dialogs,
            theme, art, audio, scanner, platform, log + app.rc
tests/      test_core.cpp — 218 בדיקות
tools/      make_icon.py (יצירת האייקון), get_zig.sh
dist/       SHOSO-Setup.exe, SHOSO-Music.exe  ← התוצרים הסופיים
```

## פתרון בעיות

* **קובץ לא מתנגן** — בשורת המצב תופיע ההודעה "הפורמט אינו נתמך על ידי נגן המדיה של Windows".
  MCI מנגן דרך המפענחים המותקנים במערכת; עבור OGG/OPUS יש להתקין את חבילת
  *Web Media Extensions* מחנות Microsoft, ועבור FLAC נדרש Windows 10 ומעלה.
* **התוכנה לא נפתחת ב‑Windows 7/8** — הקובץ מקושר סטטית אבל משתמש ב‑UCRT;
  התקינו את עדכון Windows ‏KB2999226 או את *Visual C++ Redistributable 2015+*.
* **אין קול / עוצמה לא משתנה** — אם התקן MCI לא תומך בעוצמה לכל זרם, התוכנה עוברת
  אוטומטית לעוצמת המערכת (`waveOutSetVolume`).
* **התוכנה לא נפתחת** — ייתכן שמופע אחד כבר רץ במגש המערכת; הקבצים יועברו אליו.
* **דיאגנוסטיקה** — `SHOSO-Music.exe --diag` כותב ופותח את `diagnostics.txt`;
  `--console` מדפיס את הלוג לחלון מסוף.
